# Synthetic Benchmark Results

## Scope

These values were generated by a locally executed, synthetic discrete-event assembly benchmark. They are not measurements from physical robots, a factory deployment, a geometric task-and-motion planner, or a real large language model / vision-language model.

## Execution

The main run used 4800 paired scenario instances and 24000 method-episode records across 5 methods. Each method saw the same initial state and disturbance schedule for a given scenario. The three candidate-consuming methods shared the same deterministic candidate-error draw; the rule and oracle-state symbolic baselines do not consume that candidate interface.

## Primary Summary

V-CRISP achieved a task success rate of 1.000 and a modeled-constraint rejection-attempt rate of 0.000 per dispatched action in this synthetic benchmark. The matched structured-without-verification configuration had task success 0.998 and modeled-constraint rejection-attempt rate 0.042.

## Interpretation Boundary

The comparisons support only the benchmark-specific claim that, under the declared state transitions and injected error model, pre-dispatch checking and verified suffix repair changed measured episode outcomes. The pre-dispatch checker shares its modeled action semantics with the dispatch guard; these results do not establish independent safety verification, real-world robot safety, perception robustness, LLM generalization, or industrial deployment performance.
